# Fichário de Inglês

Ferramenta pessoal de treino de recall ativo para vocabulário/expressões vistas em aula de inglês, com revisão espaçada (intervalos crescentes estilo Leitner).

- `index.html`: app completo (HTML/CSS/JS, sem build, sem dependências externas de runtime).
- Dados de progresso ficam em `localStorage` do navegador — não há backend, não sincroniza entre dispositivos/navegadores.

## Deploy

Estático puro. Build command: vazio. Output directory: `/`.
